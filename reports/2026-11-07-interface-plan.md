# Обновление интерфейса музыкальной библиотеки

Запрос: отдельная ветка, полностью новый интерфейс по референсу Spotify,
без изменения функций. Ветка: `codex/spotify-interface`.

## Дизайн

Чёрное окружение, графитовые панели, белая типографика, зелёный акцент.
Боковая медиатека, компактный обзор, спокойные диаграммы, обложки и
метаданные вместо декоративной пластинки и рекламных подписей.
Выбор исполнителя: сохранить Python-генератор и существующий JavaScript;
переписывание на отдельный frontend не требуется для визуальной задачи.

Сохранить все ID, data-атрибуты, API, подтверждения, режим dry-run,
раскрытие разделов, фильтры, сортировку, проигрывание и операции.
Поиск не закреплять. Подписи на русском, CSS/JS встроены в итоговый HTML.
Музыкальные файлы не обрабатывать. Коммиты и push не выполнять.

## План

- [x] Проверить рабочее дерево, создать ветку, выполнить исходные тесты (20).
- [x] Зафиксировать проверки контракта HTML: элементы управления, payload,
  отдельные действия карточек, пустая библиотека и экранирование.
- [x] Заменить накопленные темы единым стилевым модулем;
  обновить визуальную разметку и палитру диаграмм.
- [x] Пересобрать пример и локальный HTML из payload без сканирования музыки.
- [x] Проверить тесты, неизменность JavaScript, автономность,
  навигацию, фильтры, раскрытие и узкую ширину в браузере.
- [x] Обновить CHANGELOG и записать результаты проверки.

## Что проверить при просмотре

Длинные кириллические пути и названия; отсутствие обложек;
много элементов управления на узком экране; различимость состояний
дублей и аудиоотпечатка; сохранение скрытых блоков и индикаторов операций.

## Результаты

Окончательный вариант после проверки прав: сине-серая палитра и голубой
акцент, собственный знак каталога и favicon, компактная шапка без зелёной
плашки, прямоугольные элементы управления и лицензионные уведомления
Lucide/Feather в HTML. Пользователь отдельно разрешил коммит изменений.
Пункты ниже описывают проверки первого варианта; итоговая проверка
после исправлений — 25 тестов. Ревью выявило сдвиг объявления UTF-8
лицензионным комментарием; объявление возвращено в первые 1024 байта,
добавлен регрессионный тест, проверенный сначала на падение, затем на успех.

- `python -m unittest discover -s tests`: 23 теста успешно, исходно было 20.
- Отдельный проверяющий независимо повторил тесты и проверил CSS-состояния,
  импорты сервера и перерисовки, экранирование и автономность: замечаний нет.
- JavaScript в генераторе побайтово совпадает с HEAD. Payload примера
  совпадает с исходным; пути и метаданные не менялись.
- В браузере проверены поиск (один результат и пустая выдача), сортировка
  по альбому, фильтр аудиоотпечатка, раскрытие музыки и переходы навигации.
- Проверены ширины 390 и 320 пикселей. Обнаруженное переполнение навигации
  на 320 пикселях устранено; `scrollWidth == innerWidth == 320`.
- Проверено сравнение дублей на отдельном синтетическом HTML, без запуска
  операций с музыкой. Скриншоты обзора и сравнения обновлены в `examples/`.
- Текущий `reports/library.html` обновлён из сохранённого payload:
  1379 карточек, режим по умолчанию `dry-run`. Сканирование не выполнялось.
- Штатный сервер запущен на `http://localhost:8765/reports/library.html`.
- Музыкальные файлы не изменялись. По последующей просьбе пользователя
  итоговые изменения подготовлены к локальному коммиту без push.
