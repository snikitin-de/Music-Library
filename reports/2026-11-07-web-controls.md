# Проверка веб-списков, плеера и шрифта

Исправлены семь замечаний пользователя и два последующих уточнения.

- Вместо системного окна select — веб-меню с ролями combobox/listbox/option.
  Исходные select с ID и значениями сохранены; изменение запускает прежний
  change-обработчик. Работают выбор мышью, стрелки, Home/End, Enter, Escape,
  Tab и поиск по первым буквам. Между меню и кнопкой — 8 px; при недостатке
  места меню открывается вверх. Перемещение внутри списка не прокручивает
  всю страницу. Скроллбар шириной 6 px находится во внутреннем контейнере,
  ограниченном скруглённой внешней рамкой.
- Кнопка Play 32×32, значок 16×16 без прежнего margin-left: 2px. Измеренное
  смещение центров — 0 px по обеим осям. Ширина плеера и области тегов
  одинакова: 723 px в проверенном примере, ограничение 600 px удалено.
- Источник показан только в боковом меню. Путь выводится одной строкой
  с text-overflow: ellipsis; title содержит полный путь. Текст и атрибут
  экранированы, путь в payload сохранён.
- Вместо системного Segoe UI подключён неизменённый Inter из официального
  репозитория, локальный WOFF2 встроен в CSS как data URI. Полная лицензия
  OFL находится рядом с файлом шрифта, в THIRD_PARTY_NOTICES.md и каждом HTML.
  Источник и SHA256 записаны в scripts/assets/Inter-SOURCE.txt.
- Для круга добавлен canvas размером 560×560 при отображении 140×140 и DPR 1.
  Уменьшение сглаживает края; при другом DPI буфер пересчитывается.
  Исходный SVG остаётся запасным вариантом, подписи остаются текстовыми.
- Поля поиска и кнопки списков имеют одинаковую высоту 44 px и отступ текста
  16 px с учётом общей рамки. Отступы текста пунктов согласованы с кнопкой.

## Проверки

- 30 Python-тестов проходят. Проверки шрифта/OFL, источника и подсказки
  первоначально воспроизвели отсутствие нужного поведения, затем прошли.
- В браузере проверено: четыре веб-списка; выбор «Тег: альбом» действительно
  меняет фильтрацию; End + Enter выбирает сортировку «Формат»; Escape и Tab
  закрывают меню, Tab переводит фокус на следующий фильтр.
- End прокручивает внутренний список (scrollTop 238), scrollY страницы
  остаётся 1433 до и после.
- При 320×760 ширина страницы остаётся 320, меню помещается в окно.
  При 320×420 длинный список открывается вверх: верх 12 px, зазор 8 px.
- Независимое ревью не выявило регрессий. Дополнительное уточнение о
  скроллбаре проверено после переноса прокрутки внутрь рамки.
- Штатные обработчики музыкальных операций и данные примера не изменены.
  Музыка не перемещалась, не тегировалась и не удалялась.
