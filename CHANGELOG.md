# История изменений

Все заметные изменения проекта фиксируются в этом файле. Даты указаны в формате `ГГГГ-ММ-ДД`.

## 2026-11-08

### Сглаживание текста, кнопок и диаграммы

- Убрана зависимость от CSS-свойств сглаживания, работающих только на macOS. Для текста и элементов управления используется нейтральный стандартный фильтр; на Windows проверено исчезновение цветной каймы букв. Контейнеры навигации, всплывающих списков и окон не фильтруются, чтобы сохранить их позиционирование.
- Увеличены мелкие подписи и текст кнопок, системные радиокнопки заменены встроенными SVG с сохранением клавиатурного управления. Для режима высокой контрастности предусмотрен возврат системной отрисовки.
- Круговая диаграмма уменьшается из буфера с четырёхкратным разрешением через Canvas API с качественной интерполяцией до физических пикселей экрана; прежнее уменьшение через CSS устранено. SVG остаётся запасным вариантом.
- Проверены Windows Chromium при масштабе 100%, широкий экран и ширина 320 px. macOS и Linux в этой среде не проверялись.

## 2026-11-07

### Веб-списки, плеер и шрифт

- Нативные выпадающие окна заменены веб-списками с выбором мышью и клавиатурой, открытием вверх или вниз и скроллбаром внутри скруглённой рамки. Существующие значения фильтров и обработчики сохранены.
- Убрано смещение значка Play, плеер растянут на ширину области тегов; выровнены подписи поиска и фильтров.
- Источник возвращён в боковое меню: одна строка с многоточием и полный путь в подсказке при наведении.
- Inter встроен в автономный HTML вместе с лицензией OFL; начертания и размеры подписей смягчены. Круговая диаграмма отрисовывается с четырёхкратной плотностью пикселей и уменьшением, SVG сохранён как запасной вариант.

### Исправления отрисовки отчёта

- Стабилизирована подложка бокового меню при быстрых переходах; удалены повторяющиеся пути библиотеки и верхняя служебная строка.
- Круговая диаграмма строится SVG-окружностями; для легенды зарезервировано место под скроллбар, на узком экране диаграмма и легенда располагаются друг под другом.
- Восстановлены цветные теги, уточнены настройки отрисовки шрифтов и SVG, крестик заменён центрированной SVG-иконкой, стрелки списков отодвинуты от правого края.

### Самостоятельный тёмный интерфейс

- Светлый интерфейс заменён тёмной медиатекой с графитовыми панелями, зелёными акцентами и компактной боковой навигацией.
- Переработаны обзор коллекции, метрики, диаграммы, карточки треков, сравнение дублей и окно текста песни.
- Убраны декоративная пластинка, разноцветные плашки тегов и несколько перекрывающих друг друга CSS-тем. Единые стили находятся в `scripts/report_styles.py` и встраиваются в автономный HTML.
- Добавлена адаптация для узких экранов и видимый фокус клавиатуры; поиск остаётся обычным блоком страницы.
- Обработчики JavaScript, API, подтверждения действий и режим проверки по умолчанию сохранены.
- Добавлены проверки контракта HTML: элементы управления, действия отдельных карточек, экранирование данных и автономность отчёта.
- По уточнению пользователя восстановлены исходная компоновка тёмного варианта, круглый знак со звуковыми линиями и округлые кнопки. Зелёные оттенки слегка изменены без смены основного цвета.
- Добавлены полные лицензионные уведомления Lucide/Feather в проект и автономные HTML-отчёты, а также тест сохранения этих уведомлений.

## 2026-08-08

### Интерфейс HTML-отчёта

- Добавлены боковая навигация, новый обзор коллекции и адаптивная компоновка для широких и мобильных экранов.
- Обновлены карточки метрик и диаграммы по форматам, исполнителям, жанрам и годам.
- Текстовые и CSS-иконки заменены встроенными SVG-иконками Lucide; favicon также формируется как встроенный SVG.
- Для режимов обработки используются понятные подписи `Проверка` и `Применить изменения`, а текущее безопасное состояние видно в боковой панели.

### Работа с дублями

- В раздел дублей добавлена кнопка `Найти дубли`, запускающая полное пересканирование текущей библиотеки.
- Для повторного поиска добавлены отдельные статус и индикатор прогресса.
- После успешного пересканирования обновляются CSV дублей и автономный HTML-отчёт; файлы при этом не перемещаются.
- Подтверждение перед пересканированием и безопасный режим по умолчанию сохранены.

### Документация и примеры

- README дополнен описанием нового интерфейса, режимов обработки и повторного поиска дублей.
- Автономный пример `examples/library_nirvana_example.html` перегенерирован текущей версией отчёта.
- Прежний скриншот отчёта заменён актуальными изображениями обзора библиотеки и раздела дублей.
