# Исправление после перемещения файла

Проблема:

После `Разложить эту запись` файл переезжал и переименовывался, например:

```text
\\TRUENAS\...\Бабушкин компот - Рубеж Веков.flac
```

становился:

```text
\\TRUENAS\...\Рубеж Веков\Бабушкин компот\Рубеж Веков - Бабушкин компот.flac
```

Но HTML/CSV-отчёт продолжал хранить старый путь. Поэтому следующая операция `Проставить теги` искала старый файл и получала ошибку:

```text
Audio file was not found
```

## Что исправлено

После реальной раскладки теперь выполняется замена путей:

```text
старый путь → новый путь
```

Замена делается в двух местах:

1. список музыки внутри HTML-отчёта;
2. `reports/duplicates.csv`, если перемещённый файл был в дублях.

После этого HTML пересобирается, а кэш сервера очищается.

## Важно про дубли

После перемещения отчёт обновляет пути, но не пересчитывает заново группы дублей. Для полного пересчёта дублей нужно снова запустить `find_duplicates.py` и потом пересобрать HTML.

## После замены файлов

```bat
python scripts\generate_html_report.py --csv "reports\duplicates.csv" --library "\\TRUENAS\vault_storage\music\All music\My music\Music Test" --out "reports\duplicates.html"
python scripts\report_server.py --open
```
