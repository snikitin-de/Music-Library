# Исправление кнопок обработки музыки

Исправлено разделение действий:

## Глобальные кнопки

- `Проставить теги для отфильтрованных`
- `Разложить отфильтрованные по папкам`

Они берут только текущий отфильтрованный список.

## Кнопки внутри карточки

- `Проставить теги этой записи`
- `Разложить эту запись`

Они берут только путь из своей карточки `.music-card`.

## Защита на сервере

В `/api/music-operation` добавлен параметр `scope`.

- `scope = single` — сервер принимает ровно 1 файл.
- `scope = filtered` — сервер принимает список файлов.

Если карточка случайно отправит больше одного файла, сервер вернёт ошибку и не запустит beets.

## После замены файлов

Пересобрать отчёт:

```bat
python scripts\generate_html_report.py --csv "reports\duplicates.csv" --library "\\TRUENAS\vault_storage\music\All music\My music\Music Test" --out "reports\library.html"
```

Перезапустить сервер:

```bat
python scripts\report_server.py --open
```
