# Исправление «Разложить эту запись»

Теперь действие `Разложить` больше не зависит от `beet import`.

Почему: `beet import` мог пропускать файл как уже импортированный или дубль, поэтому папка исполнителя/альбома не создавалась.

## Новая логика

`Разложить эту запись` и `Разложить отфильтрованные по папкам` теперь:

1. читают теги файла через `mutagen`;
2. берут текущую папку библиотеки из HTML-отчёта;
3. создают папку:
   ```text
   Исполнитель альбома\Год - Альбом\
   ```
4. перемещают файл туда с именем:
   ```text
   01 - Название.flac
   ```

Если альбом не заполнен, файл уйдёт в:

```text
Singles\Исполнитель\
```

## Для тегов beets остаётся

Кнопка `Проставить теги` всё ещё использует beets.

## Важно

Для правильной раскладки у файла должны быть заполнены теги:

- `albumartist` или `artist`;
- `album`;
- `title`;
- желательно `date/year` и `tracknumber`.
